# BookTalks — Privacy Policy

The public privacy policy for the **BookTalks** iOS app, published with GitHub Pages at
<https://ahmedirtija.github.io/BookTalks-Privacy-Policy/>. That URL is the one given to
Apple App Review / App Store Connect.

`index.html` is a hand-maintained copy. The source of truth is
`BookTalks/Resources/LegalDocuments.swift` (`LegalDocuments.privacyPolicy`) in the app
repo — when you change the policy there, bump `LegalDocuments.currentTermsVersion`, then
update the text, version, and effective date here to match so the app and the web copy
never diverge.
